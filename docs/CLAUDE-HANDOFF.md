# Claude handoff

This file is intentionally a reusable task sheet. Codex will replace the
placeholder sections for each frontend assignment.

## Objective

To be written by Codex after the redesign direction is approved.

## User outcome

Describe what a visitor should understand, feel, or be able to do after the
change.

## Files Claude may edit

- List only the minimum required files.

## Files provided as context only

- `AGENTS.md`
- `CLAUDE.md`
- `DESIGN.md`
- Add relevant route, component, and token files.

## Constraints

- Preserve factual claims and fictional-data disclosures.
- Preserve static export compatibility.
- Use existing design tokens or propose token additions explicitly.
- Support mobile and desktop layouts.
- Respect reduced-motion preferences.
- Do not add dependencies without Codex approval.

## Acceptance criteria

- Add measurable visual and functional requirements for this task.
- Include responsive breakpoints or target viewport behavior where relevant.
- State which interactions and content must remain unchanged.

## Required return

Return the changed files or a patch, plus a short design rationale, checks run,
and any decisions that need Codex review. Do not deploy or push.
